# MineOS NodeJs app



![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

_MineOS NodeJs - Service for hosting your own Minecraft Server on jour HomeAssistantOS_


This App allows you to RUn jour Minecraft Server on Your HomeAssistant device.
It is based on [Hexparrots MineOS NodeJs](https://github.com/hexparrot/mineos-node) that was ported to nodeJs 24.
